# Smart Quiz Arena

A modern quiz application built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- Questions loaded from a local JSON file
- Topic-focused quizzes: History, Geography, Civics, Economics, Science, Law, Mathematics, English, Technology, and Environment
- Smooth page and element animations with Framer Motion
- Responsive, clean, modern UI
- Score tracking and progress indicator

## Tech Stack

- React (latest major)
- TypeScript (latest major)
- Tailwind CSS (latest major)
- Vite
- Framer Motion

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview production build:

```bash
npm run preview
```

## Data Source

Question data lives in [src/data/questions.json](src/data/questions.json). You can add more topics and questions there.
